# 単語帳アプリ (word-app)

英単語・古文単語などを管理し、カード型UIで学習できるWebアプリです。

## 機能

- 管理者画面で単語帳(英単語/古文単語など)と単語(word, mean, remarks)を作成・編集・削除
- 管理者画面からCSVインポート(列: `word,mean,remarks`)
- カード型のフラッシュカードUI、スマホ対応
- 4種類の出題モード
  - 英単語セット: 日→英 / 英→日
  - 古文単語セット: 現→古 / 古→現
- 出題結果を学習ログとして記録し、統計画面でグラフ表示
- Gemini APIによる単語の難易度自動判定(1〜5)、管理者画面で難易度・重要度によるソート
- 出題頻度の自動調整: 「重要度」「難易度」「5段階の自己評価による習熟度」に応じて出やすさが変わる重み付き出題
  - 重要度は数値が上がるほど出現頻度への影響が強くなる(掛け算で効く)
  - 苦手(習熟度が低い)・重要・難しい単語ほど出やすい
  - 出題画面では○✕ではなく5段階(1:全然だめ 〜 5:バッチリ)で自己評価する
- 単語の発音を音声で再生(ブラウザのWeb Speech API。英単語はen-US、古文単語はja-JPで読み上げ)
- 英単語の発音記号(IPA)を無料辞書APIから自動取得・カードに表示
- 単語をチェック(選択)してまとめてアーカイブ(出題対象から除外)。復元も可能
- アーカイブ済みの単語から単語テスト(空欄補充プリント)を自動作成
- 英単語セットでは、アーカイブ済みの単語を使った英語長文読解問題(本文+選択式設問)をGeminiで自動生成
- 作成したテスト・長文問題は画面表示のままPDFとして出力可能(印刷・配布用)
- カード学習画面(出題画面)からもその場で単語をアーカイブ可能(管理画面でのチェックに加えて)
- ある程度のオフライン対応: Wi-Fiがある時に単語帳を端末にダウンロードしておくと、電波がない場所でも出題・学習記録・アーカイブが可能。オンライン復帰時に自動で同期

## セットアップ手順

### 1. Supabaseプロジェクトを作成

1. https://supabase.com にログインし、新規プロジェクトを作成
2. プロジェクト作成後、左メニューの **SQL Editor** を開く
3. 以下のSQLファイルを **この順番で** 実行する
   1. `supabase/schema.sql` … `word_sets` / `words` / `study_logs` の基本テーブル
   2. `supabase/migration_2_gemini_proficiency.sql` … 難易度・重要度・5段階習熟度対応
   3. `supabase/migration_3_phonetic_archive.sql` … 発音記号・アーカイブ対応
4. **Project Settings > API** から以下をコピー
   - Project URL → `NEXT_PUBLIC_SUPABASE_URL`
   - `anon` `public` キー → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `service_role` キー → `SUPABASE_SERVICE_ROLE_KEY`(絶対に公開しない)
5. [Google AI Studio](https://aistudio.google.com/app/apikey) でGemini APIキーを発行 → `GEMINI_API_KEY`
   - 発音記号の取得(dictionaryapi.dev)にはAPIキー不要です

### 2. 環境変数を設定

```bash
cp .env.local.example .env.local
```

`.env.local` を開いて、上でコピーした値を貼り付けてください。

### 3. ローカルで起動

```bash
npm install
npm run dev
```

http://localhost:3000 で以下のページが使えます。

- `/` … 単語帳選択・出題モード選択
- `/admin` … 管理者画面(単語帳・単語の管理、CSVインポート、難易度/発音記号の取得、アーカイブ)
- `/stats` … 学習データの統計
- `/test/[setId]` … アーカイブ済み単語からの単語テスト・長文問題作成、PDF出力

### 4. Vercelにデプロイ

1. このプロジェクトをGitHubリポジトリにpush
2. Vercelで新規プロジェクトとしてimport(koryo-fes-resultsとは別プロジェクトにする)
3. Vercelの Project Settings > Environment Variables に、`.env.local` と同じ環境変数を設定
4. **Framework Preset が `Next.js` になっていることを確認**(`vercel.json`でも明示済み)
5. Deploy

## Gemini難易度判定・発音記号取得についての注意

- どちらも「単語1件を判定/取得するAPI」を管理画面から**1件ずつ順番に呼び出す**方式にしています。
  - 以前はサーバー側で全件をループしていましたが、Vercelのサーバーレス関数タイムアウト(無料プランは約10秒)を超えると、例えば175件中5件しか処理されずに失敗する、という問題がありました。
  - クライアント側(ブラウザ)から1件ずつ呼び出すことでタイムアウトを回避し、進捗(「◯/◯件」)も画面に表示されます。
  - 一括判定・一括取得の実行中はタブを閉じたり画面を離れたりしないでください(処理が途中で止まります)。

## 出題頻度の計算式

`app/quiz/[setId]/[mode]/page.tsx` 内の `calcWeight` 関数で計算しています。

```
重み = (難易度[未判定は3] + (6 - 習熟度) × 2) × 重要度による倍率
重要度による倍率: 1→1.0倍 / 2→1.5倍 / 3→2.0倍 / 4→2.5倍 / 5→3.0倍
```

重要度が高い単語ほど、倍率が掛け算で効くため出現頻度への影響が大きくなります。
調整したい場合はこの関数を書き換えてください。

## オフライン対応の仕組み

- ホーム画面の各単語帳カードにある「📥 オフライン用にダウンロード」を押すと、その単語帳の単語・習熟度をブラウザの`localStorage`に保存します。Wi-Fiがある時に一度これを行っておいてください。
- 出題画面(`/quiz/...`)を開いた時、オンラインならSupabaseから最新データを取得(同時にローカルキャッシュも自動更新)し、オフラインまたは通信に失敗した場合はローカルキャッシュを使って出題します。ダウンロードしていない単語帳はオフラインでは開けません。
- オフライン中の学習記録(5段階評価)・アーカイブ操作は、いったん端末内の「未送信キュー」に貯められます。画面上部に未送信件数が表示され、オンラインに戻ると自動的にSupabaseへ送信されます(手動で「今すぐ同期」も可能)。
- `public/sw.js` のService Workerにより、一度表示したページのJS/CSSがキャッシュされるため、電波が弱い状況でもアプリ自体は開きやすくなります(データはあくまで上記のダウンロード操作が必要です)。
- 制限事項: 複数の端末やタブでオフライン編集した場合の競合解決は行っていません(最後に同期した内容が優先されます)。長文問題の生成やCSVインポートなど、Gemini/管理者APIを使う機能はオンライン専用です。

## 現状の制限・今後の拡張ポイント

- **管理者画面は現在認証なし**でアクセスできます。公開後は以下のいずれかで保護することを推奨します。
  - Vercelの「Password Protection」機能(Pro以上)
  - `/admin` 配下にBasic認証をかけるmiddleware.tsの追加
  - Supabase Authを使ったログイン画面の追加(将来的にユーザーごとの学習履歴管理にも拡張可能)
- 現在は学習ログにユーザー識別子がないため、全員の記録が1つに集計されます。個人ごとに分けたい場合はSupabase Authの導入が必要です。
- CSVの文字コードはUTF-8を想定しています。Excelで作成したCSVがShift-JISの場合、文字化けすることがあるため「UTF-8で保存」してから読み込んでください。
- 発音記号は英単語のみ対応です(dictionaryapi.devの仕様上、古語には対応していません)。
- 音声再生はブラウザ標準のWeb Speech APIを使用しているため、端末やブラウザによって声質・対応言語が異なります。古文単語は現代日本語の読み上げになるため、古典的な発音の再現ではない点にご注意ください。

